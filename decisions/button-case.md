# Button label case

**Question.** Do button and control labels use Title Case or sentence case?

**Ruling (2026-10-22, owner).** Title Case for button and control labels ("Save As New", "Apply Scene"). Running text, hints and status lines stay in sentence case.

**Why.** Raised by design review round 2 (row 17 in `design/reviews/app-round2.md`), which clashed with the mockups' sentence case. The owner chose Title Case.
