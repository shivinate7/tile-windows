# App direction

**Question.** Which product direction and packaging does the full Tile Windows app take?

**Ruling (2026-10-22, owner).**
- Direction: B + C blend from the mockups (`design/mockups/index.html`). The spatial canvas of the monitors is the main screen. Saved scenes sit on its side rail and can apply themselves.
- Mockups A (command palette) and D (rule builder) are not built. Fine-tuning of that kind happens by asking Claude in a session, through the tile-windows skill.
- Packaging: Windows only for now. PowerShell engine plus the web page, with a one-line installer. No Mac build yet.

**Why.** The owner wants an app that is easy to learn and has one-click daily modes. Precise tweaks are faster to ask Claude for than to build UI for.
