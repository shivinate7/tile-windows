Setup Added Notice

When the board reads your windows and finds monitors plugged in together for the first time, it adds them as a setup. A Windows toast names the new setup, with Don't Add This Setup, which removes it and remembers the no. It is the run toast's frame and voice (decision run-undo). Dashed pink labels mark what is new; dashed grey labels mark what exists today. Each option has a switch below that hides it.
