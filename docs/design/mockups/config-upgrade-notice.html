Config Upgrade Notice

When an update adds starter scenes to your config, a Windows toast names them, with Undo. Undo removes each added scene you have not changed since. It is the run toast's frame and voice (decision run-undo). Dashed pink labels mark what is new; dashed grey labels mark what exists today. Each option has a switch below that hides it.
