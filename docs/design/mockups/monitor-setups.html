Monitor Setups: the Board

Drawn to the owner's rulings of 2026-11-17 (decision monitor-setups). Each set of plugged-in monitors is a setup. A scene's layout on a new setup follows the closest known one until you change it. Every board change is saved at once for the setup in use, so layouts have no Save or Revert; Save keeps a scene's name and triggers. Windows from an unplugged monitor wait in Windows That Stay Put and go back to their cells when it returns. Designer kind: informed. Dashed pink labels mark what is new; dashed grey labels mark what exists today.
