Free Layout on the Board

Lane L4 of Layout Free. Free Layout is a switch per monitor (and the F key). It keeps every window where it is and swaps the grid for the lines where windows meet. A plain drag moves one row's part of a line; Shift moves the whole line. Dashed pink labels mark what is new, dashed grey labels what exists today, and dotted yellow labels what is only proposed. Each option has a switch under "Show" that hides it.
